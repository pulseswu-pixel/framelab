## 修复 "fetch failed" 错误
- 根因：Promise.all 并行发送 N 个 /api/generate 请求，每个携带大量 base64 参考图，单线程 Node.js 服务器无法同时处理多个大请求+长轮询，连接被重置
- 修复：生成步骤改回串行（for 循环逐张生成），保存步骤保持并行（轻量请求）
- save-reference 添加 try-catch 容错，失败不影响生图流程

## 再次改回并行批量生成

- 修复：app.js 残留 const results=[] 导致语法错误，已移除

## 修复单张生成 fetch failed
- 根因：外部 API 返回 base64 图片数据（数MB），server 透传整个 JSON 给浏览器，fetch() 崩溃
- server.js：generate 端点拿到结果后立即 saveImage() 存本地，只返回 { url: localUrl }
- app.js：移除冗余的 /api/save-image 调用，直接用 generate 返回的 url；减少一次网络往返
